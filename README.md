# Web Accessibility Tool

白内障・色覚異常を考慮したWebアクセシビリティ評価ツールです。

## 主な機能

- axe-coreによるアクセシビリティ評価
- 白内障シミュレーション
- 色覚異常シミュレーション
- スコア表示

## 使用技術

- Node.js
- Express
- HTML / CSS / JavaScript
- axe-core

## 起動方法

```bash
npm install
node server.js

ブラウザで以下へアクセス：
http://localhost:3000
